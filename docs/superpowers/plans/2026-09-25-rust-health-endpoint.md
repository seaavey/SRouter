# Rust Health Endpoint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Serve the frozen `GET /health` contract from the standalone Rust API.

**Architecture:** Build a small Axum router with one static health handler. Start it from the Rust binary on `0.0.0.0:$PORT`, using the port parsed by `APIConfig`; do not add other listeners or routes.

**Tech Stack:** Rust stable, Axum 0.8.9, Tokio 1.53.1, Tower 0.5.3 for in-process router tests, Serde, and the existing `serde_json` dev dependency.

**Spec:** `docs/superpowers/specs/2026-09-25-rust-health-endpoint-design.md`

## Global Constraints

- The main listener binds `0.0.0.0:$PORT`; `PORT` defaults to `3000`.
- `GET /health` returns HTTP `200` and JSON `{"status":"ok"}`.
- The health handler does not query the database or providers.
- Do not add the OAuth listener, global middleware, `/v1`, static web serving, or other API routes.
- Keep `server/` independent of pnpm and `packages/*`.
- Preserve existing user changes in the shared working tree; do not stage or commit unrelated migration edits.

- [ ] **Step 2: Write the route contract test**

Create `server/tests/http_runtime.rs`:

```rust
use axum::{
    body::{to_bytes, Body},
    http::{header, Request, StatusCode},
};
use srouter_server::app::create_router;
use tower::ServiceExt;

#[tokio::test]
async fn get_health_returns_ok_json() {
    let response = create_router()
        .oneshot(
            Request::builder()
                .uri("/health")
                .body(Body::empty())
                .unwrap(),
        )
        .await
        .unwrap();

    assert_eq!(response.status(), StatusCode::OK);
    assert_eq!(response.headers()[header::CONTENT_TYPE], "application/json");

    let body = to_bytes(response.into_body(), 1024).await.unwrap();
    let json = serde_json::from_slice::<serde_json::Value>(&body).unwrap();
    assert_eq!(json, serde_json::json!({"status": "ok"}));
}
```

- [ ] **Step 4: Implement the router and health handler**

Create `server/src/app.rs`:

```rust
use axum::{routing::get, Json, Router};
use serde::Serialize;

#[derive(Serialize)]
struct HealthResponse {
    status: &'static str,
}

async fn health() -> Json<HealthResponse> {
    Json(HealthResponse { status: "ok" })
}

pub fn create_router() -> Router {
    Router::new().route("/health", get(health))
}
```

Expose the module in `server/src/lib.rs` by adding `pub mod app;` alongside the existing public modules.

- [ ] **Step 5: Run the focused route test and confirm it passes**

Run: `cargo test --manifest-path server/Cargo.toml --test http_runtime get_health_returns_ok_json`

Expected: the test passes with HTTP 200, `application/json`, and body `{"status":"ok"}`.

- [ ] **Step 6: Turn the binary entry point into the main HTTP listener**

Replace `server/src/main.rs` with:

```rust
use std::collections::HashMap;
use std::net::SocketAddr;

use srouter_server::{APIConfig, app::create_router};
use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let environment: HashMap<String, String> = std::env::vars().collect();
    let config = APIConfig::from_env_map(&environment)?;
    let address = SocketAddr::from(([0, 0, 0, 0], config.port));
    let listener = TcpListener::bind(address).await?;

    axum::serve(listener, create_router()).await?;

    Ok(())
}
```
